Quick Guide

1. Add a Tunnel

Click + add tunnel to create a new port mapping. You can add multiple tunnels to a single config.

2. Configure Fields

  • hostname: The public domain you registered in Manage Domains (e.g., mc.example.com).
  • target: Local address and port (e.g., 127.0.0.1:25565) or just port number (25565).
  • mode:
    • • http / https for web apps & REST APIs
    • • minecraft for Vanilla Minecraft servers
    • • minecraft-proxy for PaperMC/Bungee with proxy-protocol: true
    • • tcp / tcp-proxy for raw TCP services (SSH, DB, Game servers)

3. Save & Run

After saving the configuration, open your terminal and start the tunnel using the gotunnel run command shown above.
