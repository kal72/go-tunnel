Panduan Penggunaan Go-Tunnel

Dokumentasi ini menjelaskan langkah-langkah untuk menghubungkan layanan lokal Anda ke internet menggunakan go-tunnel, mulai dari konfigurasi di sisi server (Web UI) hingga menjalankan client.

1 Persiapan di Web UI (Server)

Sebelum client dapat terhubung, Anda harus menyiapkan akses dan mendaftarkan subdomain di server melalui Web UI.

  • Daftarkan Subdomain: Gunakan fitur Domain Manager untuk mendaftarkan subdomain secara manual, atau biarkan sistem menghasilkan subdomain secara otomatis (auto-generate).
  • Generate Auth Token: Di menu Manage Configs, buat file config baru. Masukkan client_id, dan klik tombol generate token (ikon refresh atau kunci).
  • Simpan Konfigurasi: Download file konfigurasi .yaml yang dihasilkan untuk digunakan di sisi client.

2 Membuat File Konfigurasi (Client)

Jika Anda lebih memilih untuk membuat file config.yaml secara manual di sisi client Anda, silakan buat file tersebut dan sesuaikan isinya sebagai berikut:

# Koneksi ke listener tunnel di server
tunnel_addr: "{{.TunnelAddr}}"
skip_tls_verify: false

# Autentikasi dari Web UI
client_id: "office-laptop"
auth_token: "token-anda-disini"

# Mapping host -> target layanan lokal
tunnels:
  # Contoh untuk mengekspos layanan HTTP (Web)
  - hostname: "app.domainanda.com"
    target: "127.0.0.1:8080"
    mode: "http"
    
  # Contoh untuk mengekspos layanan raw TCP (misal: SSH/Database)
  - hostname: "ssh.domainanda.com"
    target: "127.0.0.1:22"
    mode: "tcp"

3 Menjalankan Client

Langkah terakhir adalah menjalankan aplikasi client. Buka terminal Anda dan jalankan perintah berikut di dalam direktori tempat file konfigurasi Anda berada:

$ ./client-binary -config config.yaml

Client akan otomatis membentuk koneksi yang aman ke server. Jika autentikasi berhasil, layanan lokal Anda dapat langsung diakses secara publik melalui URL / Hostname yang telah Anda tentukan.

4 Konfigurasi Custom Domain

Jika Anda ingin menggunakan nama domain Anda sendiri (misalnya app.namaperusahaan.com) alih-alih menggunakan subdomain default, ikuti langkah-langkah berikut:

  • 1. Konfigurasi DNS (CNAME): Buka panel pengaturan DNS domain Anda (Cloudflare, Namecheap, Route53, dll). Buat record baru dengan tipe CNAME yang mengarah ke alamat public gateway server tunnel ini (misal: gateway.vpskamu.com).
  • 2. Daftarkan di Domain Manager: Masuk ke menu Manage Domains di Web UI ini. Tambahkan custom domain Anda (misal: app.namaperusahaan.com) ke dalam daftar domain yang diizinkan (allowlist).
  • 3. Update Config Client: Ubah nilai hostname pada file config.yaml di client Anda menjadi custom domain tersebut. Restart aplikasi client Anda.

Sistem akan secara otomatis melakukan proses negosiasi dan meng-generate sertifikat SSL/TLS (Let's Encrypt) gratis untuk custom domain Anda saat trafik pertama kali masuk. Proses ini mungkin memakan waktu beberapa detik pada kunjungan pertama.
